# Prior-path pre-read injection v2 (frozen protocol)

Three randomized arms: `SOURCE_ONLY`, `TMF_TOOL`, `TMF_INJECT_ONLY` (never inject+tool). Each phase is a new independent session. First visit autonomously searches/reads target and persists only minimal navigation state (`repo_id`, path, symbol/region if observed, timestamp, first-visit memory/event IDs, source hash); never answer/transcript/prompt/golden. Before UserPromptSubmit and any current source read, INJECT reads only prior-tool-trace state and conservatively injects bounded Top-3 fresh claims (<=1200 tokens) for that path, regardless of current prompt relevance; stale becomes a path-only reread pointer. Unknown and unrelated phases measure noise. SOURCE and TOOL get no preload; TOOL alone may lookup after source touch. Source is authoritative.

Injection tokens count in total. Fresh injected anchors are citations; stale pointers require localized reread. Same source budgets and symmetric repair. Freeze protocol/manifest/tasks/goldens/scorer/audit/tests before smoke; smoke one sequence, then three only if valid. Gate: no INJECT accuracy regression, fresh revisit reduces reads/lines or total cost versus SOURCE, mutation no stale errors and localized reread; compare TOOL. Never derive a path from current prompt/golden.
