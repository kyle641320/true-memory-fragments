# Revisit-memory v3 preregistered protocol

Independent replacement experiment; v1/v2 are immutable and are not regraded. Three newly held-out Java sequences use new declarations, facts, booleans, and mutations. The order is real first visit, unchanged fresh revisit, unknown-identity miss, then a tree containing both semantic and unrelated mutation. CONTROL rereads authoritative source. TMF_MEMORY may reuse only the first-visit source-bound memory identity while fresh, must miss unfamiliar regions, and must block stale adoption before one-file localized reread.

The broker is instructed with a strict JSON Schema. Both arms undergo identical structural validation for required enums, requested integer/boolean field, and non-empty path-line citations. At most one preregistered format-repair inference is permitted per task. It receives only raw output, schema, structural error list, and already-read evidence for citation recovery. It is forbidden to alter semantic values/enums, infer an answer, read new source, or receive a golden. Repair tokens and latency are included.

The frozen scorer checks only requested structured fields, instrumentation enums, and citation path-line coverage. Primary metrics are typed correctness and citation coverage. Secondary metrics are source lines/bytes, total tokens/latency, memory hit/adoption, repair rate/cost, stale errors, and stale-detection/localized-reread precision/recall. Freeze precedes execution. One-sequence smoke is the stop gate; the three genuinely distinct sequence pilot runs only if smoke is valid/correct in every paired arm/phase and audits pass. If formatting still invalidates smoke, stop and rule the pinned broker model unsuitable; there is no v4.
