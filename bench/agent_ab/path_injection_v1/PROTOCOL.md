# Path-triggered memory injection v1 — frozen preregistration

Independent held-out comparison of `SOURCE_ONLY`, `TMF_TOOL`, and `TMF_INJECT_ONLY`; injection and tools are never combined. Tasks were authored without consulting v3 outcomes. All arms use gpt-5.6-sol, identical task order, randomized arm order, source/call/time limits, and symmetric schema-only repair.

A controlled stateless agent loop receives the task and ordinary `search`, `read`, and `finish` actions. TMF_TOOL additionally receives `tmf_lookup`; no memory is preloaded or hinted. Search results derive from the agent query. The first source read is first code touch and records target/path/symbol provenance. First-visit claims are source-bound to that trace. On independent revisits only, INJECT hooks after that genuine touch and packs matching fresh local claims (Top3, <=1200 estimated tokens) as non-instructional, source-authoritative memory. Unknown paths miss. Stale claims yield only a localized reread pointer. Answers, transcripts, prompts, and goldens are forbidden memory inputs.

Phases: first visit, unchanged revisit, unknown region, semantic mutation, unrelated mutation. Freshness uses file SHA-256. Semantic staleness blocks facts and triggers one-file reread; unrelated mutation retains freshness. Metrics: accuracy/citation, source lines/bytes/files, tokens/latency, TMF calls/adoption, injection hit/adoption/tokens, stale errors and localized precision/recall. Injection tokens count in total prompt usage and separately. Validity requires complete transcripts, isolation, budgets, provenance, and freshness behavior.

Smoke=P21. Pilot=all three only after passing smoke. Stop on validity failure; no v2. Product gate: injection improves accuracy, or is non-inferior while materially reducing repeated reads/total cost, and exceeds or explains TOOL. n=3 is directional. One symmetric format repair may preserve semantic fields and repair schema/citations from already-read evidence only; no golden or new source.
