For an event with no matching subscribers, `EventBus.post(Object)` first calls `SubscriberRegistry.getSubscribers(event)`, obtains an empty iterator, and—when the branch is present—calls `EventBus.post(new DeadEvent(this, event))`. That recursive `post` again calls `SubscriberRegistry.getSubscribers(DeadEvent)`; if a `DeadEvent` subscriber exists, its non-empty iterator reaches `dispatcher.dispatch(deadEvent, eventSubscribers)`. Removing the branch eliminates this entire recursive `EventBus.post` → `SubscriberRegistry.getSubscribers(DeadEvent)` → `Dispatcher.dispatch` path, so dead events are silently dropped.

Consequently, for such originally unsubscribed events, the dispatch implementations that can no longer be reached are `Dispatcher.PerThreadQueuedDispatcher.dispatch` (the dispatcher used by ordinary `EventBus`), `Dispatcher.LegacyAsyncDispatcher.dispatch` (used by `AsyncEventBus`), and, when an `EventBus` is constructed with the immediate dispatcher, `Dispatcher.ImmediateDispatcher.dispatch`. The initial `post` does not invoke any dispatcher because its subscriber iterator is empty; only the reposted `DeadEvent` could have reached these concrete subclasses.
