With the DeadEvent re-post branch removed, `EventBus.post(Object)` no longer takes the no-subscriber path from its `else if (!(event instanceof DeadEvent))` arm: it will not construct `new DeadEvent(this, event)` or recursively call `post(Object)` for that wrapper. Consequently, the follow-on path through `SubscriberRegistry.getSubscribers(...)` for the `DeadEvent`, and then `Dispatcher.dispatch(Object, Iterator<Subscriber>)` to deliver the `DeadEvent`, is no longer reachable for an original event with no subscribers.

That makes every concrete `Dispatcher` implementation unreachable on this specific no-subscriber/dead-event path: `Dispatcher.PerThreadQueuedDispatcher.dispatch(...)` (the dispatcher created by `Dispatcher.perThreadDispatchQueue()` and used by ordinary `EventBus`), `Dispatcher.LegacyAsyncDispatcher.dispatch(...)` (created by `Dispatcher.legacyAsync()` and used by `AsyncEventBus`), and `Dispatcher.ImmediateDispatcher.dispatch(...)` (the singleton returned by `Dispatcher.immediate()`). Their normal paths for events that do have subscribers remain reachable; only the dispatch of the reposted `DeadEvent` is eliminated.
