# TMF Launch Copy

## Short version

TMF is source-aware memory for AI coding agents. It binds code-graph claims to source fingerprints and blocks stale context before an agent acts on obsolete code understanding.

## One-line pitch

Prevent AI coding agents from trusting code understanding that is no longer fresh.

## Social post draft

I’ve been working on TMF (True Memory Fragments): source-aware memory for AI coding agents.

Instead of caching stale facts, TMF binds code-graph claims to source fingerprints. When a claim goes stale, it blocks the expansion and sends the agent back to current source.

Think: stale-context protection for coding agents.

Repo: https://github.com/kyle641320/true-memory-fragments

## README summary sentence

TMF does not make an agent remember more. It prevents the agent from trusting code understanding that is no longer fresh.
